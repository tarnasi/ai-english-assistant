# Workplace English Assistant

An alpha desktop app that helps you understand a manager's message in English
and prepare a suitable reply. Paste a message into the app to get a Persian
explanation and three suggested English responses.

## Alpha version

The current alpha provides:

- A simple desktop interface built with Python's Tkinter.
- A text box for pasting a manager's message. The app does not connect to
  Telegram or send messages; you review and copy replies yourself.
- Local AI analysis through Ollama's chat API, using `gemma3:latest` by
  default.
- A Persian translation of the original message, its explicit request,
  possible intent, and any important unknown context.
- Three concise English reply options with different tones, Persian
  translations, and guidance on when each might be appropriate.
- A recommended reply, with a Persian explanation of why it is a suitable
  choice.
- Buttons to copy each English reply and clear the current analysis.
- A background request so the interface remains responsive while the model
  works, plus user-visible error messages for connection, timeout, and response
  format problems.

The suggestions are generated by an AI model and should be reviewed before
use. The app uses a fixed local Ollama address (`http://localhost:11434`) and
model (`gemma3:latest`) in this alpha. It does not retain a conversation
history or provide Telegram integration.

## Requirements

- Python 3.14 or newer.
- Tkinter, which is commonly included with Python but may need to be installed
  separately on some Linux distributions.
- [Ollama](https://ollama.com/) running locally, with the `gemma3:latest` model
  available.

## Setup and run

1. Install Ollama and download the model:

   ```bash
   ollama pull gemma3:latest
   ```

2. Make sure the Ollama service is running and its local API is available at
   `http://localhost:11434`.

3. Run the application from the project directory:

   ```bash
   python main.py
   ```

No additional Python packages are declared for the app; it uses Python's
standard library.

## Using the app

1. Paste the manager's message into the text box.
2. Select **Analyze message** and wait for the local model to respond.
3. Review the Persian analysis and the three reply cards.
4. Use **Copy English reply A/B/C** to copy a response, then decide whether to
   send or edit it yourself.
5. Select **Clear** to remove the message and results.

## Project status

This is an early alpha centered on one workflow: manually analyzing an
English-language workplace message and drafting a response. Telegram
connectivity, message sending, persistent history, and model configuration are
not part of the current implementation.
